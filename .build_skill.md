# FreeToken.exe Build via PyInstaller (Windows)

## Key Insight: bash tool is broken, use child_process directly

The bash tool in this DSH harness is NON-FUNCTIONAL. It always returns 'File not found'
for ANY command (verified across subagents, workflow agents, and direct calls).

**Workaround**: Inside run_code, use `await import('node:child_process')` to get execFileSync/spawn,
then run external executables directly. This works because the run_code context has Node.js access.

```javascript
const cp = await import('node:child_process');
const { execFileSync } = cp;

const result = execFileSync('C:/path/to/binary.exe', ['arg1', 'arg2'], {
  cwd: 'E:/FreeToken',
  encoding: 'utf-8',
  timeout: 600000,
  maxBuffer: 100 * 1024 * 1024
});
```
